🐛 2. PERBAIKAN BUG KRITIS & STABILITAS SISTEM
Kami membersihkan sistem dari berbagai bug mengganggu untuk kenyamanan maksimal:
👉 🛠️ **Regex Bypass Fix**: Memperbaiki kegagalan mirroring otomatis pada beberapa link TikTok/Twitter/X/Instagram. Sekarang link video akan dikirim secara instan tanpa terlewat!
👉 🛡️ **Bypass Rate Limiter**: Membatasi bypass link maksimal 3 kali per 30 detik per user untuk mencegah spam webhook.
👉 ⚙️ **Dotenv Loading Fix**: Memperbaiki pemuatan variabel lingkungan pada startup bot agar lebih presisi.
👉 🚪 **Graceful Shutdown**: Bot akan menutup koneksi suara secara bersih saat dimatikan/di-restart di VPS, mencegah error koneksi.
👉 🔠 **Koreksi Typo**: Memperbaiki kata seperti "terlahu" -> "terlalu", dan "Ambal" -> "Ambil".
👉 👤 **Owner ID Dynamic**: Menggunakan ID Owner dinamis dari file konfigurasi lingkungan, bukan hardcoded.
